# Raffinement Matériel (Hardware)

## 1. Optique
- Ajouter une lentille macro devant l'objectif OV2640 pour faire le focus de très près (quelques cm de la boîte de Pétri).
- Utiliser un support imprimé en 3D pour maintenir une distance focale fixe.

## 2. Éclairage
- Intégrer un diffuseur (papier calque ou plastique opalin) pour uniformiser la lumière des LEDs latérales.
- Utiliser un MOSFET pour contrôler l'intensité de l'éclairage via PWM depuis l'ESP32.

## 3. Structure
- Boîtier étanche ou résistant à l'humidité pour une utilisation sécurisée en incubateur.
- Support réglable pour différentes tailles de boîtes de Pétri.
