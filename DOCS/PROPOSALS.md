# Propositions de Fonctionnalités (Standard)

## 1. Connectivité Cloud
- Envoi automatique des images vers un serveur FTP ou une Google Drive via Wi-Fi.
- Dashboard web pour visualiser les statistiques de comptage en temps réel.

## 2. Interface Utilisateur
- Utilisation d'un buzzer pour confirmer la capture.
- Ajout d'un encodeur rotatif pour naviguer dans les menus.

## 3. Analyse de Données
- Génération d'un fichier CSV sur la carte SD avec : Heure, Date (via NTP), Compte Lactiques, Compte Contaminants.
- Calcul automatique de la concentration (UFC/ml) en saisissant le facteur de dilution.
